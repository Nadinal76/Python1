ID: BUG-01
Компонент: класс StringUtils, метод capitalize()
Критичность: Major (Высокая)

Название: Метод capitalize() некорректно преобразует строку, переводя весь текст в верхний регистр.

Шаги воспроизведения:
1. Инициализировать класс: utils = StringUtils()
2. Вызвать метод с тестовой строкой: utils.capitalize("skypro")

Фактический результат: Метод возвращает строку "SKYPROkypro".
Ожидаемый результат: Метод должен вернуть строку "Skypro" (только первая буква заглавная).

Рекомендация по исправлению:
Заменить текущую строку возврата:
return string.upper() + string[1:]
На корректную логику работы со срезами:
return string[0].upper() + string[1:]
